여행 팁
✓ 2장 이상 다른 브랜드 준비
한 카드 거절 시 대비. VISA + Mastercard 조합 추천. AMEX나 JCB만 갖고 가면 낭패 가능.
✓ 지역별 유리한 카드
일본: JCB + VISA / 미국: VISA + AMEX / 유럽: VISA + Mastercard / 중국: UnionPay 필수 / 동남아: VISA + JCB
✓ 트래블카드는 필수
환전 수수료 + 해외 결제 수수료 아끼려면 트래블로그 or 트래블월렛 하나 이상 발급. 결제 시 원화(KRW) 아닌 현지 통화로 결제해야 이중 환전 방지.
✓ 카드 정지 대비
해외 사용 전 카드사에 사전 여행 등록. 갑자기 해외 결제 시 카드사 부정 사용 판정으로 정지될 수 있음.
